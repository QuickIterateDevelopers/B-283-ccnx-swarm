(1) 指示コンソール task-command / fault-inject / scenario

救助タスク投入(故障ロボ回収)

選んだロボを停止(NEEDS_RESCUE)させ、その位置へ2機で救助 → 病院搬送で復活。
→ /task/rescue/robot/?/carriers/2

おうちに戻れ

全機を ControlCenter へ帰還(/command/home)。着いたら星拾いに戻る。救助中の機は継続。

エリア集中指令

10秒間、全機が指定エリア内の星だけを対象にする(/command/focus/{zone})。救助は優先継続。

シナリオ制御

reset=全体再配置 / respawn=停止機の再起動
(2) 応答表示ウィンドウ log-event / packet-event
(3) ロボ動作表示画面 Canvas2D · 座標はC決定値を描画 · rAF補間

🏁 このデモのルール

  1. 🤖 9体のロボットが 赤・青・緑の3チーム(各3体)に分かれて自律行動する
  2. ⭐ フィールドの星を拾い、自チームの回収箱に入れると1個獲得
  3. 🏆 星が尽きたらゲームセット。箱の星が最多のチームが優勝
  4. 💥 ロボはときどき故障して停止し「助けて🆘」を発信する(左の操作パネルから故障させることもできる)
  5. 🚑 近くの仲間2機が自己選抜で駆けつけ、担いで病院へ搬送すると復活する
  6. 📡 指令・救助・報告はすべて CCNx(RFC8569/8609)の「名前」で交換される — 宛先IPは一切指定しない
  7. 🔍 左のログには実ワイヤ(Interest / Content Object)がそのまま流れる(Wireshark でも観測可)
  8. 🎮 左ペインからセマンティック名の命令を投入して、自分で介入できる
  9. 📦 回収箱はドラッグ&ドロップで移動できる — 星の密集地に寄せて、特定のチームが有利になるよう導くこともできる(移動も実 CCNx /bin/{team}/moved で全機へ伝わる)
